# 「拜师」AI 导师技能 · 实现说明

> 一份可复制的玩法文档：教一个对话式 AI 扮演「师父」，用「出题 → 批改 → 落库 → 跨会话续学」的闭环，带徒弟做长期、需要反馈的刻意练习。
> 本文以「中医医案」为例，但整套模式可平移到编程、外语、考试、写作等任何「练＋改」的领域。

## 一、这套东西的本质

它不是一个「插件」，而是五个零件拼起来的模式（缺一不可）：

1. **人设与节奏**（persona + 分阶段，让 AI 有「师父」的说话方式和推进节奏）
2. **教学闭环**（师父出题 → 徒弟作答 → 结构化批改）
3. **能力底座**（能「落库」的工具，把每次练习沉淀下来）
4. **结构化笔记**（约定 frontmatter，让沉淀可检索、可复盘）
5. **跨会话记忆锚点**（一份契约文件 + 一句唤醒提示词，新会话不掉线）

## 二、零件一：人设与节奏（persona + 阶段）

给 AI 一段 persona（系统提示），要点：

- 明确「你是师父，不是答疑机器」；
- 明确教学节奏：先问清目标 → 分阶段推进 → 一次别给太多；
- 明确「先复述再往下问」，让徒弟觉得你在「把脉」而非「填表」。

**节奏模板（对应百花拜师的五阶段）**：入道（摸底）→ 筑基（打基础）→ 精进（进阶）→ 磨砺（刻意练习/纠错）→ 出师（独立）。

## 三、零件二：教学闭环 + 批改结构

闭环三步：**师父出题 → 徒弟按固定格式作答 → 师父结构化批改**。

**作答格式（中医例）**：八纲＋六经、病机、治法、方（方名＋药物＋剂量＋煎服法）、服后预期。
（编程例：思路、复杂度、代码、测试用例、边界条件。）

**批改结构（万能模板，这是整套模式的灵魂）**：

1. 总评（一句话定调：对 / 错 / 对一半）
2. 逐条：先「抓对的」再「抓错的」，错的必讲「为什么错」
3. 给正确结论 + 标准答案
4. 点一个「可教的鉴别点」（同类易混处的分水岭）
5. 肯定亮点（哪怕做错了也要找到对的地方）

> 关键：**批改要落在「错因」上，而不是只给答案**。徒弟真正长进，靠的是知道「哪一步、为什么走偏」。

## 四、零件三：能力底座（落库工具）

要「积累」，AI 需要能写知识库的工具。以百花为例，用了 MCP 的 5 个工具：

- `baihua_vault_create` —— 建知识库
- `baihua_vault_write_note` —— 写笔记（markdown）
- `baihua_vault_read_note` —— 读笔记（复习）
- `baihua_vault_search` —— 检索（按关键词/语义找旧医案）
- `baihua_vault_list` —— 列知识库

实现位置：`services/Baihua.Family/Services/Mcp/BaihuaMcpTools.cs`（挂在 `/mcp` 端点，streamable-http）。

> 这些工具原本只有「读」，本次补了 `create` 和 `write_note` 两个「写」工具，才让「边练边积累」落地。别的项目可用任何等价能力（文件、数据库、向量库、Obsidian…），只要 AI 能「写」且「检索」。

## 五、零件四：结构化笔记（frontmatter 约定）

每篇练习写成一个带 YAML 头的 markdown，正面是「正文（原题＋作答＋批改）」，头部是「可检索的元数据」：

```markdown
---
type: 医案
tags: [医案, 太阳病, 伤寒表实, 麻黄汤]
case_no: 001
证型: 太阳伤寒表实证
方剂: 麻黄汤
错因: 过度辨证_误判少阴合病_方不对证
date: 2026-08-30
---
```

别的领域照改字段：编程用 `type: 练习 / 考点 / 错因 / 复杂度`；外语用 `type: 作文 / 错误类型`；考试用 `题号 / 章节 / 错因`。**「错因」字段是精髓——复习按错因翻，比按章节翻更值钱。**

## 六、零件五：跨会话记忆锚点（契约文件 + 唤醒提示词）

对话 AI 通常没有跨会话记忆。解决办法不是「记住」，而是「外部化」：

1. 建一份**契约文件**（如 `docs/BAISHI_MASTER.md`），固化：师父身份、目标与定位、**进度快照**、练习格式约定、安全红线、唤醒提示词。
2. 新会话发一句**唤醒提示词**，让 AI 先读契约文件恢复记忆：

```
继续「百花拜师」。你是我师父。先读 <契约文件路径> 恢复契约与进度，再继续教我。
```

> 进度快照要**每次练完就更新**，否则新会话读到的是旧进度。这是整套模式里唯一需要人/AI 主动维护的状态。

## 七、安全红线（专业领域通用）

- 医疗／法律／投资等专业内容：一律标注「教学练习，不构成真实处方/意见」；
- 高风险操作（发汗峻剂、剧毒药、高杠杆）必须保守；
- 不承诺收益、不鼓励非理性目标（如「5 万炒到 500 万」要被师父摁下来）。

## 八、三步迁移到你的领域

1. 写一段 persona（把上文的「师父」换成你的场景角色）；
2. 定一套 frontmatter（把「证型／方剂」换成你的「考点／错因」）；
3. 建一份契约文件（写目标 + 进度快照 + 唤醒提示词）。

完。
